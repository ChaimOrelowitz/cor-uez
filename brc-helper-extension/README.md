# COR UEZ Document Helper

This Chrome extension runs only after a UEZ admin clicks a BRC or tax-clearance button in the COR UEZ admin app. It opens the required New Jersey pages, leaves any human verification visible, and sends the resulting PDF to the selected applicant's UEZ file.

## Install once

1. Open `chrome://extensions` in Chrome.
2. Turn on **Developer mode**.
3. Click **Load unpacked**.
4. Choose the `brc-helper-extension` folder from this repository.
5. Reload the COR UEZ admin page.

After extension code is updated, click **Reload** on this extension's card in `chrome://extensions`.
